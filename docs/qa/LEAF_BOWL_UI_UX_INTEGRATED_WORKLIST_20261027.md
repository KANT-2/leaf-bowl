- 기준: [읽기 전용 감사](LEAF_BOWL_UI_AUDIT_READONLY_20261027.md)의 `UI-01`~`UI-13`과 사용자가 제공한 ZIP `LEAF_BOWL_UIUX_v2.1-v2.4_ORIGINAL_SOURCE_PACK_20261027.zip`의 원본 7개. ZIP 안의 `docs/qa/uiux_reference_20261027/00_START_HERE.md`를 먼저 읽고 원본의 지정 절을 대조했다. 원본은 ZIP 내부에 있으며 작업 폴더에 별도 추출하지 않았다.
- 출처 약어: `D` = `LEAF_BOWL_DESIGN_SYSTEM_v2.1_20261027.md`(v2.0 본문 포함), `M` = `LEAF_BOWL_QA_IMPLEMENTATION_MATRIX_v2.1_20261027.md`(v2.0 매트릭스 포함), `W` = `LEAF_BOWL_UX_WRITING_CONTROLS_ADDENDUM_v2.3_20261027.md`, `G` = `CODEX_LEAF_BOWL_APPROVAL_TYPOGRAPHY_GOVERNANCE_v2.4_20261027.md`, `감사` = 위 읽기 전용 감사 보고서 §C. `M UI-001`~`UI-021`은 원본 문서 ID이고 `감사 UI-01`~`UI-13`은 신규 감사 ID다.
- `CODEX_LEAF_BOWL_QA_EXECUTION_v2.1_20261027.md`, `CODEX_LEAF_BOWL_PLUS_5H_OPTIMIZED_v2.2_20261027.md`, `CODEX_LEAF_BOWL_UX_MICROTASKS_v2.3_20261027.md`는 범위·우선순위 참고용 실행 카드로만 사용했다. 그 카드의 구현 지시는 실행하지 않았다.
- 출처 `원본`: 사용자 제공 v2.1/v2.3의 요구·QA 기준. `감사 추가`: 이번 감사가 새로 발견한 문제·제안. `원본+감사`: 같은 문제에 대한 양쪽 근거. 원본의 `권장`·`추천`도 설계 승인으로 간주하지 않는다.

- 범위·QA 공통 조건: 고객과 관리자의 기존 디자인 체계, 브랜드 색, API/저장 계약 유지. 실제 데이터 저장·결제·주문 변경 없이 가능한 시각/키보드 QA를 먼저 한다. 1440×900, 768×1024, 390×844에서 확인하고 문제가 있는 곳은 320px 및 200% 확대를 추가한다. 열린 드롭다운/달력/모달은 위·중간·끝 스크롤, Tab·Escape·외부 클릭·포커스 복귀·화면 충돌을 확인한다. 모바일 터치 목표 44×44px. 12px 미만의 읽어야 하는 한글 텍스트는 허용하지 않는다. 실제로 확인하지 않은 상태는 PASS로 표시하지 않는다.

## 중복 통합·요구 추적

- `UI-01`/`UI-03`/`UI-12`는 각각 고객 헤더·관리자 로그인·관리자 공통 셸의 **서로 다른** 768px 문제이므로 분리했다. 공통 폭 검증은 `X-01`에 한 번만 둔다.
- `UI-04`는 메뉴의 카드 소실 결함, `C-01`은 메뉴 탐색 전체 흐름이다. `UI-10`은 초기화 문구로 분리했다. `UI-02`는 주소 검색의 의미·정확성, `UI-06`은 7개 탭의 접근성이다.
