# 디자인 시스템 v1.1 적용·검증 기록

검증일: 2026-10-27. 작업 브랜치: `feat/design-system-v1.1`.

## 적용 범위

- spacing/type/radius/icon/상태 토큰 추가. 기존 색상 유지.
- 고객 메뉴·이벤트와 관리자 검색을 SearchField/FilterGroup 계약으로 통일.
- 가격 입력 검증·빈 값 무제한·초기화·로딩/오류/빈 결과 구분.
- native 정렬 select 유지, SVG chevron 적용.
- 관리자 DialogHeader/DialogBody/DialogFooter 분리, 본문 스크롤과 고정 액션.
- 작은 읽기용 글자 12px 이상으로 조정, 주요 본문·조작 글자 14px 적용.
- 320px 결제 요약의 최소 너비를 컨테이너 이내로 제한.
- 실제 컴포넌트 사용처가 없는 이전 이벤트 검색·필터·빈 결과와 관리자 검색 CSS 116줄 제거.

API·DB·backend·주문 상태 전이 변경 없음. 공용 DB에 주문 생성이나 상태 변경 테스트를 하지 않았다.

## 브라우저 확인

- 고객 화면: `/`, `/menu`, `/event`, `/match`, `/product/0`, `/reviews`, `/login`, `/checkout`, `/drinks`.
- 너비: 320/375/390/600/640/700/768/900/901/1024/1280/1440/1920px, 높이 900px.
- 총 117개 화면·너비 조합에서 document 가로 넘침 0px 확인.
- 표시되는 HTML 텍스트 12px 미만 없음. 모바일 배너의 투명 링크(0px, 접근성 이름 제공)는 화면 표시 텍스트에서 제외했다.
- Claude가 1~5단계 diff와 화면 실측 검토: 메뉴·이벤트·관리자 검색 높이 44px, 검색 X 중복 없음, 메뉴 가격 오류 단일 표시, 초기화 시 정렬 복원 확인.
- Claude가 375×600 관리자 메뉴·리뷰 모달에서 본문 스크롤, 헤더·하단 액션 노출과 닫기 버튼 44px 확인.
- 이벤트 로딩·오류 경계와 필터별 빈 결과는 코드 검토 대상. 모든 네트워크 오류·서버 데이터 조합을 브라우저에서 강제로 재현한 것은 아니다.
- 마지막 스크린샷 저장은 브라우저 창 최소화로 실패했다. 이번 기록의 화면 크기별 수치는 DOM 실측이며 스크린샷 첨부는 없다.

## 자동 검증과 기존 환경 제약

단계별 `npm run lint`, `npm test`, `npm run build`, `npx tsc --noEmit` 실행.

- ESLint 통과. 전체 lint의 Prettier 단계는 기존 CRLF 체크아웃 파일 때문에 실패한다. 변경 파일은 LF·Prettier 검사를 별도로 통과했다. 전역 포맷 재작성은 하지 않았다.
- 최종 전체 lint의 포맷 경고는 315개 파일이다. 별도 사용자 수정 파일도 전체 검사에 포함된다.
- 테스트 166개 중 155개 통과, 11개는 기존 파일 잠금 테스트의 Windows symlink EPERM 실패. Claude 독립 재현 및 사용자 승인에 따라 기존 환경 실패로 기록한다.
- production build 및 별도 TypeScript 검사 통과. 일부 빌드에서 기존 Next 보안 진단으로 종료 후 재실행이 필요했다. 의존성 업그레이드는 이번 범위에서 수행하지 않았다.

## 유지한 예외·후속 후보

- SVG 내부 그래픽 좌표 글자 및 관리자 이미지 미리보기 모형의 작은 글자는 요청된 예외로 유지.
- 관리자 모달 ESC 종료 뒤 편집 트리거로 포커스가 복귀하지 않는 기존 동작, 모바일 상품 편집 버튼의 기존 접근성 이름 누락은 별도 수정 후보. 이번 스타일 작업에서 행동 계약은 변경하지 않았다.
- 고객은 Pretendard variable dynamic subset, 관리자는 CDN Pretendard를 사용한다. 로컬 패키지 라이선스는 OFL-1.1. 고객 CSS 55,760바이트·92개 font-face는 CSS 크기이며 폰트 전송량을 뜻하지 않는다. 실제 네트워크·캐시 측정 전 로딩 방식 통일은 보류했다.
- 별도 사용자 수정 파일 `app/(customer)/page.tsx`, `app/api/reviews/route.ts`와 기존 추적되지 않은 SQL/PDF/보조 스크립트는 커밋에서 제외한다.

push·PR·배포는 수행하지 않는다.
