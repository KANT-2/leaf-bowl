# 원산지·알레르기 로컬 데이터 점검 (2026-10-12)

이슈: #148. 원산지는 전부 가상 데이터다. 사용자 요청으로 화면의 `(예시)` 표시와 원산지 상세 메모는 삭제했다. 실제 납품 원산지를 나타내지 않는다. 로컬 관리자 DB만 변경하고 운영/검증 DB에는 적용하지 않는다.

## 확인 범위

등록 재료 18개와 메뉴 21개의 현재 안내를 확인했다. 이름과 구성 재료만으로 납품 제품의 전체 성분, 레시피, 교차접촉을 검증할 수 없으므로 알레르기 누락이 없다고 보증하지 않는다. 빈 안내는 알레르기가 없다는 뜻이 아니다.

- 식약처 안내의 국내 표시대상: 알류(가금류), 우유, 메밀, 땅콩, 대두, 밀, 잣, 호두, 게, 새우, 오징어, 고등어, 조개류(굴·전복·홍합 포함), 복숭아, 토마토, 닭고기, 돼지고기, 쇠고기, 아황산류(최종제품 이산화황 10mg/kg 이상).
- 연어·참치·아몬드·참깨도 알레르기 원인이 될 수 있으므로 국내 목록에 없다는 이유로 기존 안내를 삭제하지 않았다. 병아리콩을 대두로, 보리를 밀로 취급하지 않는다.

## 데이터 반영

18개 원산지 예시는 `origin-demo-data.json`에 기록했다. 기존 ID·순서·가격·이미지·노출 설정·알레르기 안내는 보존한다. 그릴 치킨(닭고기), 새우(새우), 연어(연어), 두부(대두), 토마토(토마토), 부라타(우유), 크루통(밀), 믹스 넛츠(땅콩·호두·아몬드)의 기존 안내를 유지한다.

레몬 치킨 아보카도에는 현재 구성 재료에 토마토가 있으나 메뉴 알레르기 안내에 누락되어 있으므로 `토마토`를 추가한다. 기존 닭고기·연어 안내는 유지한다.

## 실제 납품표·레시피 확인이 필요한 항목

| 항목 | 확인 내용 | 이번 처리 |
| --- | --- | --- |
| 크루통 | 우유·알류·대두 함유 여부 | 밀 유지, 이 문서에 확인 메모 |
| 믹스 넛츠 | 실제 견과 종류, 잣·캐슈넛 등 추가 원료 | 기존 3종 유지, 이 문서에 메모 |
| 치킨·연어·새우·구운 버섯 | 버터·간장·마리네이드 등의 우유·대두·밀 | 확정 추가하지 않고 이 문서에 메모 |
| 블랙 올리브·발사믹 | 아황산류 함유 및 최종제품 함량 | 확정 추가하지 않음 |
| 참깨 드레싱 | 기존 대두·밀·참깨 외 알류 등 | 기존 안내 유지, 제품표 확인 필요 |
| 시저 드레싱 | 우유·알류·생선 외 대두·밀, 생선 종류 | 기존 안내 유지, 제품표 확인 필요 |
| 머쉬룸 그레인 | 현재 밀 안내의 근거, 보리와 밀의 혼동 여부 | 레시피 미확인으로 밀 안내 유지 |
| 음료 4종 | 실제 착즙/혼합 원료, 첨가물, 우유 등 추가 성분 | 이름만으로 무알레르기 확정하지 않음 |
| 모든 메뉴 | 등록되지 않은 페타·파르메산·참치·스테이크·에다마메 등, 선택 드레싱, 공용 조리도구 | 기존 메뉴 안내 보존, 전체 레시피와 교차접촉 확인 필요 |

기존 계란 표기는 유지했다. 국내 표준 문구로 정리할 때는 공급사 원재료표에 맞춰 알류(가금류) 등으로 통일해야 한다. 확인되지 않은 성분을 포함으로 단정해서 입력하지 않았다.

사용자 후속 요청: 원산지의 `(예시)` 접미사와 모든 원산지 상세 내용을 비웠다. 위 확인 필요 사항은 문서에만 보존한다.
